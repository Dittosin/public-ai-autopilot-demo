# 국민 AI 오토파일럿 데모

「AI 에이전트로 일상 바꾸기」 정책공모전 제안서에 활용하기 위한 개인 공공 AI 에이전트 프론트엔드 데모입니다.

> 정책을 추천하는 AI가 아니라, 다음 할 일을 찾는 AI.

사용자의 확인된 현재 상태와 앞으로의 목표를 하나의 미션으로 관리하고, 취업·전입·계약처럼 상황이 달라지면 다음 행동을 다시 판단하는 경험을 보여줍니다.

## 공개 데모

[GitHub Pages에서 데모 열기](https://dittosin.github.io/public-ai-autopilot-demo/)

## 대표 시나리오

대표 사용자는 만 24세 대학 졸업예정자로, 현재 미취업 상태에서 부모와 거주하며 서울 취업과 이후 독립을 희망합니다.

1. 첫 화면에서 “졸업하고 서울에서 취업해서 독립하고 싶어요” 목표 확인
2. `서울 취업하고 독립하기` 미션 생성
3. 지금 할 일로 취업·직업훈련 지원 확인
4. AI가 서울 청년주택 신규 공고를 지켜봄
5. 임대차계약 이후 월세지원을 다시 확인하도록 대기
6. “취업했어. 강남에서 12월부터 출근해.” 상태 변화 체험
7. 미션 전체 재판단 후 주거지원 확인이 새로운 다음 행동으로 변경
8. 지원 확인 → 목적별 동의 → 신청 준비 → 사용자 최종승인

사용자 화면에서는 내부 상태 코드를 노출하지 않고 `지금 할 일`, `AI가 지켜보는 중`, `나중에 다시 확인`이라는 행동 중심 표현을 사용합니다.

## 안전·신뢰센터

설정의 안전·신뢰센터에서 AI가 할 수 있는 일과 한계, 목적별 데이터 동의, 사용자 최종 승인, 활동 기록, 오류·이의제기, 사람 연결, 보안 취약점 신고 원칙을 확인할 수 있습니다. 법률문서와 신고 채널은 실제 운영을 가정한 짧은 UI 예시이며, 실제 접수나 기관 연결 기능은 구현하지 않았습니다.

## 데모 범위와 한계

이 프로젝트는 `src/data/mockData.ts`의 mock 데이터만 사용하는 React 프론트엔드 목업입니다.

- 실제 간편인증 없음
- 실제 공공 마이데이터 조회 없음
- 실제 개인정보 저장 또는 외부 전송 없음
- 실제 정책 자격 판정 없음
- 실제 정부 신청 또는 제출 없음
- 별도 백엔드와 데이터베이스 없음

정책명과 판단 결과는 시나리오 기반 데모 예시입니다. 실제 서비스에서는 사용자 동의에 기반한 공공 마이데이터 이용체계, 참여기관 연계, 정책·공고 변경 수집, 본인인증, 소관기관 신청 시스템이 필요합니다. 최종 자격과 처분은 해당 기관이 결정해야 합니다.

## 실행 방법

```bash
npm install
npm run dev
```

기본 개발 주소는 `http://127.0.0.1:5173/`입니다.

프로덕션 빌드:

```bash
npm run build
```

## 코드 구조

- `src/components`: 앱 셸, 하단 메뉴, 버튼, 진행 단계 등 공통 UI
- `src/pages`: 목표 입력, 미션 홈, 동의, 신청 준비, 승인, 기록, 설정 화면
- `src/data/mockData.ts`: 청년 프로필, 미션 전후 상태, 동의, 신청서, 감사로그 데이터
- `src/types.ts`: 화면, 미션, 행동 상태, 신청 실행 관련 타입

GitHub Actions와 Vite의 저장소별 `base` 설정을 사용해 `main` 브랜치를 GitHub Pages에 배포합니다.
