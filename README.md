# 국민 AI 오토파일럿 데모

「AI 에이전트로 일상 바꾸기」 공모전 제안서에 활용하기 위한 React 프론트엔드 데모입니다.

이 서비스는 정책을 한 번 추천하고 끝나는 챗봇이 아니라, 사용자의 확인된 현재 상태와 앞으로의 목표를 하나의 미션으로 관리하고 상황이 달라질 때 다음 행동을 다시 판단하는 개인 공공 AI 에이전트 모델을 보여줍니다.

> 정책을 추천하는 AI가 아니라, 다음 할 일을 찾는 AI.

## 대표 실증 시나리오

대표 사용자는 만 24세 대학 졸업예정자로, 현재 부모와 수도권에 거주하며 서울 취업과 이후 독립을 희망합니다.

1. 간편인증 데모
2. 필요한 공공정보를 목적별로 연결하는 동의 화면
3. 확인된 현재 상태 자동 구성
4. 세 가지 시작 경로 선택
5. “졸업하고 서울에서 취업해서 독립하고 싶어” 목표 입력
6. `취업하고 독립하기` 미션 생성
7. 행동을 `NOW / WATCH / WAIT`로 분류
8. 취업 확정 이벤트 후 미션 전체 재판단
9. `NOW` 항목에서 신청 준비 시작
10. 목적별 동의 → 신청서 초안 → 사용자 최종승인

정책명과 판단 결과는 모두 시나리오 기반 데모 예시입니다. 구체적인 자격, 지원 금액, 모집 기간을 실제 정보처럼 제공하지 않습니다.

## 핵심 개념

- `NOW`: 현재 실제 행동할 가치가 있는 항목
- `WATCH`: AI가 정책·공고 변화를 대신 지켜보는 항목
- `WAIT`: 조건이 생기면 다시 판단할 항목
- `DROP`: 현재 조건이나 우선순위에서 제외한 항목
- 상태 변화 재판단: `미취업 → 취업 확정` 변화에 맞춰 다음 행동을 다시 구성
- 사용자 승인 기반 실행: AI가 신청을 준비하되 사용자 승인 없이 제출하지 않음

첫 실증 범위는 취업, 직업훈련, 주거, 이사, 청년 생활지원으로 제한했습니다. 향후 AI 국민비서·공공 AI 인프라와 연계 가능한 특화 에이전트 모델을 지향합니다.

## 데모 범위와 한계

이 프로젝트는 `src/data/mockData.ts`만 사용하는 프론트엔드 목업입니다.

- 실제 간편인증 없음
- 실제 공공 마이데이터 조회 없음
- 실제 개인정보 저장 또는 외부 전송 없음
- 실제 정부 신청 API 연동 없음
- 별도 백엔드와 데이터베이스 없음
- 실제 정책 자격 판정 없음

실제 서비스에서는 사용자 동의·제공요구에 기반한 공공 마이데이터 이용체계, 참여기관 연계, 본인인증, 소관기관 신청 시스템, 정책·공고 변경 수집 체계가 필요합니다. 공식 자격 판정과 처분은 소관기관 시스템이 수행해야 합니다.

## 실행 방법

```bash
npm install
npm run dev
```

기본 개발 주소는 `http://127.0.0.1:5173/`입니다.

프로덕션 빌드:

```bash
npm run build
```

## 코드 구조

- `src/components`: 공통 앱 셸, 버튼, 상태, 진행 단계 UI
- `src/pages`: 온보딩, 미션보드, 동의, 신청 준비, 승인, 기록, 설정 화면
- `src/data/mockData.ts`: 청년 프로필, 미션 전후 상태, 목적별 동의, 신청서, 감사로그 mock 데이터
- `src/types.ts`: 화면, 미션, 행동 상태, 신청 실행 데이터 타입

GitHub Actions와 Vite의 저장소별 `base` 설정을 사용해 `main` 브랜치 변경사항을 GitHub Pages에 배포합니다.
